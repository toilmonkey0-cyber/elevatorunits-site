05 — Privacy

This site does not collect personal data.

Last updated November 4, 2026. This page covers these website files. The extension is described after that.

Canonical public privacy policy

The website

These pages are static. There are no accounts, no cookies set by ElevatorUnits, no analytics, and no advertising. Fonts are files shipped with the site. The pages do not call Google Fonts, a payment processor, or a form vendor.

The sample lookup compares what you type with a Palm Beach file included in the page. The script does not send that text, the match, or an account anywhere. The sample is not the live DBPR extract.

The readiness form’s action is #form-placeholder. The page script stops the submit and shows that nothing was sent. It does not call a server. There is no third-party form service. If the script does not run, the browser posts to that placeholder on this same page, still not to a form vendor.

The reserve button’s address is #stripe-placeholder. It does not open Stripe and it does not charge a card.

The extension

ElevatorUnits does not collect personal data, and it does not send personal data anywhere. Lookups run on the device. The extension reads the address, name, or license number you highlight, compares it with a copy of the Florida DBPR elevator file stored in that browser, and shows the match in the panel. The highlighted text and the last result stay in chrome.storage.local on that device. The elevator file stays in IndexedDB in the extension. Download progress stays in chrome.storage.session, which Chrome clears when the browser closes.

The only network call from the extension is a download of the public DBPR elevator extract from https://www2.myfloridalicense.com/sto/file_download/extracts/elevator.csv. The request does not include the highlighted text, the lookup result, or an account.

The extension does not use accounts, cookies, analytics, advertising, or chrome.storage.sync. It does not sell data. It does not use data for credit or lending. Removing the extension deletes the extract and the last lookup from that browser.

The same extension text is in docs/PRIVACY.md in the project, last updated October 30, 2026.
